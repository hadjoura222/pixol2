What is Base64?

          

            Base64 is a binary-to-text encoding scheme that represents binary data in an ASCII string format.
            It is commonly used when binary data needs to be stored or transferred over media designed to
            handle text — such as HTTP headers, JSON fields, or email attachments.
          

          

            Common uses include encoding images in CSS data URLs, passing credentials in HTTP Basic Auth
            headers, and encoding binary file content in JSON APIs.
